# The Long Debt in Unreal

`Data/StoryCampaign.json` is a byte-for-byte JSON export of `SpacePatriotCampaign.project()` from the original `campaign-data.js` (project `space-patriot-long-debt-v1`). It contains nine cases, 90 Storyworks nodes, 27 gameplay objectives, 18 endings, all original dialogue, prerequisites, choice flags, and faction/economy reward payloads. The export was compared to the original JavaScript object. JSON SHA-256: `4244485a2806be607ba6be97e1189b2eb584d7d709825ee8eec73ace677839b7`.

`USPStoryCampaignComponent` loads the graph, tracks active nodes, applies prerequisite gates, accepts choices, records journal text and outcome flags, and saves progress in `USPSStoryCampaignSaveGame`. It uses the existing `USPSocietySimulationComponent` for cargo-backed deliveries, credits, standing, and market stock. Add both components to the authoritative game actor, set the `Society` reference, and call `InitializeCampaign` after the society has initialized. The integrated map's I key now opens a read-only case journal built from `GetQuestSummaries`, `GetCurrentNode`, and recent journal entries. It shows active objective progress and destinations, available cases, dialogue choices, completed cases, and recent records. Port boards still own case selection and choice actions through H/M/1/2. `OnNodeChanged` and `OnRewardGranted` are presentation events.

Interaction actors should call `SignalGameplay(kind, worldId, uniqueEventId)` only after their actual terminal, station, survey, reactor, or combat interaction succeeds. Delivery objectives use `DeliverObjective(questId, worldId, confirmedAtPort)`; the docking system must provide the port check and the campaign validates and consumes hold cargo before advancing the graph. World IDs such as `earth` and source display names such as `Earth` both resolve through `Data/Worlds.json`. `SignalGameplay` rejects delivery so a generic event cannot bypass cargo accounting. `SaveCampaign` persists to `SpacePatriotLongDebt`; the society component retains its own save slot. Host authority and UI routing must be supplied by the owning game mode before multiplayer use.

`SpacePatriot.StoryCampaign.FullGraph` traverses all 27 objectives and all nine cases twice, selecting both ending branches. It checks prerequisite gates, duplicate event rejection, seven cargo-backed deliveries, faction/economy rewards, outcome flags, source journal text, and save-memory roundtrips. Integrated tests also cover the I-key journal and a valid field-sample campaign signal. World travel, terminal interactions, and the journal are now player-reachable in the integrated map, but most objective kinds and choice encounters still need actual interaction actors, consequence presentation, and a unified transactional save. Separate campaign and society slots leave a narrow crash window between reward application and both saves; production migration should store them in one host save transaction.
