# Worldworks surface slice in Unreal

`ASPWorldSurface` is a native Unreal actor for the part of the original world
renderer that has been migrated so far. Run `Tools/SPWorldCreateMaterial.py`
and then `Tools/SPWorldIntegrate.py` inside Unreal Editor to place **one** actor
at the local world origin in `L_KestrelFlight`. The integration script is
idempotent and verifies the saved map by reloading it. `WorldId` selects one
of the 19 IDs in `Data/Worlds.json`.
The actor finds the player pawn automatically, or `FocusActor` may be assigned.
`RebuildSurface` can be invoked in the Editor to preview the mesh. Set its
`SurfaceMaterial` to `/Game/SpacePatriot/Materials/M_WorldVertex`, generated by
`Tools/SPWorldCreateMaterial.py`.

The `Data/Worldworks/*.bytes` files are the original 129×129 local terrain
fields for all 13 solid worlds. `Data/Worldworks/Climate/*.bytes` are the
original 256×128 planetwide climate atlases for all 19 worlds. The C++ reader
keeps the original little-endian header, seed, grid coordinates, four float
channels, and bilinear sampling. It also ports the original 64-cell periodic
noise, source body-frame mapping, globe-scale relief, protected port basin,
and 2.4–3 km fade from local terrain into planetary relief. The source
atmosphere shader, water simulation, cities, vegetation engine, and full
local geology branch still need Unreal implementations.

The globe mesh uses 128×64 segments and provides coarse collision across
solid worlds while the local patch is unavailable. A single curved
detail patch follows the pawn at every surface location. It spans 6 km,
concentrates vertices near the pawn, and uses 96, 48, or 24 segments depending
on altitude. Detail collision is enabled only below 400 m and is cooked
synchronously before replacing the old collision body. The patch hides above
`MaxDetailAltitudeMeters` (default 1200 m), and rebuilds after a bounded
120 m or 700 m focus move. This allows an arbitrary surface location to be
approached without keeping high-detail terrain around the whole planet.
The far globe remains a lower-detail collision fallback. At walking altitude,
the local patch takes over collision because the sparse globe can differ from
the visible detail by metres and would otherwise intercept the character.

`Tools/SPWorldFieldAudit.py` checks all 32 copied binary files against the
Unity source export, all seeds, grid dimensions, and world coverage. It writes
`Data/WorldFieldAudit.json`. Run it from this repository with Python. The
project's packaging settings stage `Data/`, so the source fields remain
available in packaged builds.

After map placement, `Tools/SPWorldValidateRuntime.py` activates all 19 worlds
in the Editor, checks 13 solid-world local fields, six gas-world exceptions,
the 19 climate atlases, the detail mesh budget, and distinct relief. Its
`integrated_map_actor` report flag must be true for a saved-map validation.

`ASPWorldSurface::SampleAtWorldLocation` exposes elevation, moisture,
temperature, rock, forest and color channels for later ecology/placement
actors. The 19/13/19 data coverage is verified; visual and gameplay parity
with every original world is not yet established.
